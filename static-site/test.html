Issue: Can't see splash screen or login page?

Likely Causes:

  1. CSS file path issue
  2. VS Code Live Server not serving from correct folder
  3. Browser cache
  4. JavaScript console errors

Test the pages:

Test Splash Screen Test Login Page Test Profiles Page

Instructions:

  1. Right-click on index.html in VS Code
  2. Select "Open with Live Server"
  3. Press F12 to open DevTools
  4. Check the Console tab for errors
  5. Check the Network tab - is style.css loading?
  6. Try a hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
